# Mutation Testing Weak vs Strong Tests

This example demonstrates the core concept of mutation testing. It shows how a weak test suite might fail to detect a subtle code change (a 'mutant'), leading to a 'survived mutant'. Conversely, it illustrates how a robust test suite successfully 'kills' the mutant by failing when the code is altered, highlighting the importance of comprehensive test cases beyond simple code coverage.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
